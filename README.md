# 수학왕 3학년 (Android)

초등학교 3학년 수학 학습용 Android Studio 프로젝트입니다.

## 구현된 기능
- 3학년 1·2학기 12개 단원 메뉴
- 하·중·상 난이도 선택
- 단원별 20문제 세션
- 숫자 입력 및 자동 채점
- 정답 해설 표시
- 틀린 문제 자동 저장(앱 내부 SharedPreferences)
- 단원·난이도별 오답 다시 풀기
- 오답 재도전에서 맞히면 오답 목록에서 제거
- 간단한 학습 점수 저장

## APK 만들기
1. Android Studio 최신 안정 버전에서 이 폴더를 엽니다.
2. Gradle 동기화를 완료합니다.
3. `Build > Build Bundle(s) / APK(s) > Build APK(s)`를 선택합니다.
4. 생성된 APK를 안드로이드 기기에 설치합니다.

## 참고
현재 포함된 문제 생성기는 앱 동작을 확인하기 위한 기초 문제 템플릿입니다.
실제 학교 교과서의 차시·성취기준과 일치하는 완성형 문제은행으로 사용하기 전에는
교과서 출판사와 교육과정에 맞춘 문항 검수 및 보강이 필요합니다.
또한 현재 버전은 객관식보다 숫자 입력형 중심입니다.


## GitHub에서 APK 자동 빌드하기
이 프로젝트에는 `.github/workflows/build-apk.yml` 자동 빌드 설정이 포함되어 있습니다.

1. ZIP을 풀고 전체 프로젝트를 본인의 GitHub 저장소에 올립니다.
2. GitHub 저장소의 **Actions** 탭에서 **Build Android APK**를 선택합니다.
3. **Run workflow**를 실행합니다. `main` 브랜치에 올려도 자동 실행됩니다.
4. 빌드가 성공하면 실행 결과의 **Artifacts**에서 `SuhakWang3-debug-apk`를 내려받습니다.
5. ZIP 안의 `app-debug.apk`를 안드로이드 기기로 옮겨 설치합니다.

현재 실행 환경에는 Android SDK와 Gradle 빌드 환경이 없어 이 대화 안에서 APK 바이너리를 직접 컴파일·검증하지는 못했습니다.
